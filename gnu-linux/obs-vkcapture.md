#    OBS VK GAME CAPTURE    #

- [obs-vkcapture source](https://github.com/nowrep/obs-vkcapture)

#### Uso:
```bash
obk-gamecapture "path-juego"
```
> Si es OpenGL o Vulkan el juego, este comando se encarga de usar lo que necesite.

#### Exportando var, para VK games:
```bash
export OBS_VKCAPTURE=1

"ejecutar-juego"
```
