# HTML Estilos bonitos

En html el atributo `style` es usado para derle estilo a los elementos, cambiar el color, fuente, tamaño, y mas.

Ejemplo:  
<span style="color:red">Texto rojo</span>  
<span style="color:blue">Texto azulito</span>  
<h1>Texto grande</h1>




# El atributo de estilo HTML  
La configuración del estilo de un elemetno HTML se pude realizar el atributo `style`.
El HTML `style` el atributo tiene la siguiente sintaxis:  
```html
<tagname style="property:value;">
```

> Aprendera más sobre CSS más adelante en este tutorial




# Color de fondo
El CSS `background-color` la propiedad define el color de fondo para un elemento HTML

Ejemplo  
Establezca el color de fondo de una página azul pálido:  
```html
<body style="background-color:powderblue;">

<h1>Este es un titular</h1>
<p>Esto es un porrafo</p>

</body>
```

Ejemplo  
Establecer e lcolor de fondo para dos elementos diferentes:
```html
<body>

<h1 style="background-color:powderblue;">Este es una cabezera</h1>
<p style="background-color:tomato;">Este es un parrafo.</p>
```



# Color de texto
La propiedad de CSS `color` define el color de texto para un elemento HTML:

### Ejemplo
```html
<h1 style="color:blue;">Este es un heading</h1>
<p style="color:red;">Este es un parrafo</p>
```




# Fuentes de texto
El CSS `font-family`, la propiedad define la fuente que se utilizará para un elemento HTML:

### Ejemplo
```html
<h1 style="font-family:monospace;">Esto es un heading</h1>
<p style="font-family:courier;">Esto es un parrafo</p>
```




# Tamaño del texto
El CSS `font-size` la propiedad define el tamaño del texto para un elemento HTML:

### Ejemplo
```html
<h1 style="font-size:300%;">Este es una cabezera</h1>
<p style="font-size:160%;">Este es un parrafo</p>
```




# Aliniación de texto
La propiedad de `text-align` define la alineación horizontal del texto para un elemento HTML.
```html
<h1 style="text-align:center;">Centrar heading</h1>
<p style="text-align:center;">Centrar parrafo</p>
```

# Resumen de capitulo
Usa `style` para darle estilo a los elemenotos.
Usa `background-color` para establecer el color de fondo.
Usa `color` para el color del texto
Usa `font-family` para la fuente de texto.
Usa `font-size` para el tamaño del texto
Usa `text-align` para el alinear texto.
