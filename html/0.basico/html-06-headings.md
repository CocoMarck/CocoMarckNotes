# HTML Headings

Los encabezados HTML son títulos o subtitulos que desea mostrar una página web.

Ejemplo:
# Heading 1
## Heading 2
### Heading 3
#### Heading 4
##### Heading 5
###### Heading 6




## Encabezados HTML

Los encaezados HTML se definen con el `<h1>` a `<h6>`.
`<h1>` define el encabezado más importante. `<h6>` define el encabezado menos importante.

Ejemplo:
```html
<h1>Haeding 1</h1>
<h2>Haeding 2</h2>
<h3>Haeding 3</h3>
<h4>Haeding 4</h4>
<h5>Haeding 5</h5>
<h6>Haeding 5</h6>
```

*Nota: Los navegadores agregan automáticamente algunos espaccos en blanco (un margen) antes y después de un encabezado.*




## Los headers son importantes  
Los motores de búsqueda utilizan los encabezados para indexar la estructura y el contenido de sus páginas web.

Los usuarios sueles hojear una página por sus encabezados. Es importante usar encabezados para mostrar la estructura del documento.

`<h1>` Los encabezados deben usarse para los encabezados principales, seguidos de `<h2>` encabezados, entonces los menos importantes `<h3>`, etcétera.

*Nota: Use encabezados HTML solo para encabezados. No los use para crear texto. GRANDE o negrita.*




## Headers más grandes  
Cada header HTML tiene un tamaño predeterminado. Sin embargo, puedes especificar el tamaño de cualquier heade. Con el `style` atributo, usando el CSS `font-size` propiedad:

### Ejemplo  
```html
<h1 style="font-size:60px;">Heading 1</h1>
```
