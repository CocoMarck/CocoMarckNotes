# HTML Editores
Un editor de texto simple es todo lo que necesitas para aprender HTML.

Aprenda HTML usando el bloc de notas o el equivalente en su sitema operativo.

Para crear código html, tenemos que crear `archivos.html`

Asegurate de ponerles de extención de rachivo `.html`

## Ejemplo `index.html`
```html
<!DOCTYPE html>
<html>
<body>

<h1>Mi primer hading</h1>

<p>Mi primer paradigma</p>

</body>
</html>
```

Por ahora al archivo siempre ponle nombre de `index.html`, guardalo así.

Para ver dicho archivo puedes darle dos clicks al archivo.html, o puedes abrir el navegador y arrastrarlo en el, o copiar la dirección del archivo y pegarla en el navegador.
