# ¿Que es HTML?
[enlace](https://www.w3schools.com/html/)

HTML es el lenguaje de mercado estandar para pagínas web
Con HTML puedes crear tu propio sitio web.
HTML es fácil de aprender; ¡Lo disfrutaras!

Aprendizaje fácil con HTML: ¡Pruebalo tú mismo!

**Ejemplo de código HTML:**
```html
<!DOCTYPE html>
<html>
<head>
<title>Pag Title</title>
</head>
<body>

<h1>Este es un heading</h1>
<p>Este s un paradigma</p>

</body>
</html>
```
